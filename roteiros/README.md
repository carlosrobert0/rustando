# Roteiros

O curso segue o Rust Book. Um projeto entra a cada 3–4 aulas (ver [../canal/padroes.md](../canal/padroes.md#roteiro-do-curso-o-curso-é-a-base)).
Todo roteiro novo tem: abertura de 30 s escrita palavra por palavra, erros propositais **com a mensagem real do
compilador** (conferida antes), um único pedido de like depois do melhor momento, título, thumbnail, descrição e
capítulos.

## Regras que valem pra todo roteiro (vieram dos dados do canal)
1. Nada de cumprimento, vinheta ou apresentação antes do gancho. O resultado aparece nos primeiros 5 s.
2. **Nunca dizer "então é isso" no meio do vídeo.** Soa como fim: no #4 Parte 1 a retenção caiu de 52% pra 42% logo depois.
3. Máximo de 15 min. Se passar, vira duas partes.
4. Cada erro proposital é compilado antes, e o roteiro traz a mensagem real.
5. Um CTA só, depois da revelação. Os últimos 20 s são a tela final.
6. No fim, dizer qual é o próximo vídeo. Ele já fica na tela final.
