# Legendas corrigidas

Geradas em 15/10/2026 a partir das legendas automáticas dos vídeos, com os erros de reconhecimento trocados pelo
termo certo. Os principais: "Hust"/"Rush" → Rust, "struc" → struct, "trade" → trait, "HIP" → heap,
"steack" → stack, "cargo RAM" → cargo run, "Hustálise" → rust-analyzer, "Husting" → rustup, "crepes" → crates.
Também saíram as marcações erradas como "[roncando]".

- `.srt`: com tempo. Use nos vídeos **que você não cortou** (Studio → Legendas → Adicionar → Enviar arquivo → Com tempo).
- `.txt`: só o texto. Use nos vídeos **que você cortou** (Studio → Legendas → Adicionar → Sincronização automática).

A troca é automática, então pode ter sobrado algum erro menor de reconhecimento (palavras comuns). O Studio
deixa revisar e editar antes de publicar.

Pra regenerar (ex.: depois de um vídeo novo), peça pro Claude: *"gera a legenda corrigida do vídeo <link>"*.
